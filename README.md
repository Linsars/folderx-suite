# FolderX Suite

> **Archived** — 个人学习项目，已停止维护。核心功能已合并至上游 [folderx](https://github.com/example/folderx)。

SpringBoard 美化套件:文件夹主题变色 / 充电限制 / Wi-Fi 永连 / 系统增强。

## 功能

- 🎨 文件夹主题与配色(多套预设)
- 🔋 充电限制(80% 电池保护, 特权 daemon 实现)
- 📶 Wi-Fi 永连(休眠不断网)
- 🧩 系统增强(应用版本伪装等)

## 安装

Dopamine / TrollStore 环境, 添加源或手动安装 deb。设置入口:系统设置 → TweakSettings → MinisFix。

## 构建

`make package`(theos), 或使用仓库自带 GitHub Actions。
